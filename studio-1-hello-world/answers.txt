- int printf(const char *format, ...);
- int fprintf(FILE *stream, const char *format, ...);

The main difference between printf and fprintf is their output destination. printf always writes formatted data directly to the standard output (stdout), fprintf allows you to send formatted data to any specified file stream, such as a file on disk or the standard error stream (stderr).

4. "The functions in the printf() family produce output according to  a format  as  described  below.  The functions printf() and vprintf() write output to stdout, the standard output stream;  fprintf()  and vfprintf()  write  output  to  the  given output stream."

11. 
- When to use fprintf(): When we are writing a program that needs to run on any computer (Windows, Mac, Linux) and print text easily. 
- When to use write(): When we are building a high-speed web server or a system tool that needs to send data directly to the internet or hardware as fast as possible.
